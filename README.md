# agent-rules — הנחיות אוניברסליות לכל הסוכנים

מקור יחיד להנחיות "איך לעבוד עם שמואל", לכל כלי ולכל ספק.

- `AGENTS.md` — ההנחיות עצמן. זה הקובץ היחיד שכל סוכן חייב לקרוא.
- `RATIONALE.md` — מאיפה כל כלל הגיע. לא נטען אוטומטית; קוראים לפני שמציעים לשנות כלל.
- `CLAUDE.md` — מפנה ל-`AGENTS.md` בלבד, לכלים של Claude.

## איך כל כלי טוען את ההנחיות

| כלי | איך |
|---|---|
| Claude Code (CLI) | `~/.claude/CLAUDE.md` מכיל `@~/.agent-rules/AGENTS.md`; `~/.agent-rules` הוא קישור לעותק המקומי של המאגר הזה |
| Codex CLI | `~/.codex/AGENTS.md` הוא קישור ל-`~/.agent-rules/AGENTS.md` |
| Claude באפליקציה / בדפדפן (Projects) | לחבר את המאגר דרך מחבר GitHub, ובהוראות הפרויקט: "בתחילת כל שיחה לקרוא את `AGENTS.md` מהמאגר `samraanan/agent-rules` ולפעול לפיו" |
| ChatGPT / סוכן ענן אחר | כמו באפליקציה: חיבור GitHub למאגר הזה בלבד + אותה הוראה |

**גישה:** המאגר פרטי. סוכן חיצוני מקבל גישה למאגר הזה בלבד — לא למאגרי הפרויקטים.

## עריכה וסנכרון

- עורכים כאן בלבד, ואז commit ו-push רגיל. GitHub הוא המקור המשותף.
- עותק מקומי: `git pull --ff-only` לפני עריכה, כדי לא לדרוס עדכון מסביבה אחרת.
